# 高中物理平台框架（只含必修）

這版定四件事：課題和知識點怎麼切、三種題怎麼批、掌握程度和錯題本怎麼算、運行時要接什麼。畫面原型在 `prototype/index.html`，示例成績只為看版面。

課程範圍依照上傳的《高中物理 — 必修部份》學與教策略參考（報考 2016 年及以後香港中學文憑試）。選修部分不納入。

## 五個課題

| 次序 | 課題 | 時數 | 子課題 |
| --- | --- | --- | --- |
| 01 | 熱和氣體 | 23 | 溫度、熱和內能；熱轉移；物態的改變；氣體 |
| 02 | 力和運動 | 50 | 位置和移動；力和運動；拋體；作功、能量和功率；動量；勻速圓周運動；引力 |
| 03 | 波動 | 47 | 波的本質和特性；光；聲音 |
| 04 | 電和磁 | 48 | 靜電學；電路和家居用電；電磁學 |
| 05 | 放射現象和核能 | 16 | 輻射和放射現象；原子模型；核能 |

合計 184 小時、79 個知識點。整體掌握按這五個時數加權，所以力和運動、波動、電和磁比放射現象重。

## 學生和教師各自看什麼

學生有四個畫面。

- **掌握情況**：五個課題的得分率、覆蓋了多少知識點、目前最弱的一點。可按課程順序，或把較弱的課題排到前面。
- **課題**：該課題每一個知識點的等級。點進去才看到細項，首頁不會一次鋪開全部知識點。
- **做題**：交卷後立刻看到分數、錯在哪、正確步驟或要點，並寫明記入哪個知識點。
- **錯題本**：未拿滿分的題。待重做、重做仍錯、已掌握三種狀態。

教師看**班別**：五個課題的班平均，以及最低的幾個知識點。用同一份知識點清單，方便對上個人頁。班別頁不排學生名次。

下一課可以從「班上仍低、而你即將教到」的知識點來選。尚未開課的知識點只算覆蓋，不混進最低分。

## 知識點

每題掛一個主要知識點。要再記一個相關點也可以，掌握計算只用主要那個，避免一題拉動太多條。

**熱和氣體**

- 溫度與溫標；熱與內能；熱容量與比熱容量
- 傳導、對流與輻射
- 熔解、凝固、沸騰與凝結；熔解比潛熱與汽化比潛熱；蒸發與冷卻效應
- 波義耳定律、氣壓–溫度與體積–溫度；普適氣體定律；分子運動論

**力和運動**

- 距離與位移；標量與矢量；速率與速度；勻速運動；加速度；勻加速運動方程；重力下的垂直運動
- 牛頓第一定律與慣性；力的合成與分解；牛頓第二定律；牛頓第三定律；質量與重量；力矩、力偶與重心
- 拋體運動
- 機械功；重力勢能；動能；能量守恆；功率
- 線動量；動量變化與淨力；動量守恆與碰撞
- 勻速圓周運動
- 萬有引力與引力場

**波動**

- 波的本質；橫波、縱波與波的術語；位移線圖與相位；波速；波的反射與折射；繞射；疊加與干涉；橫波駐波
- 電磁波譜與光速；光的反射與平面鏡；光的折射；全內反射；薄透鏡成像；楊氏雙縫；平面透射光柵
- 聲音的波動本質；聽頻與超聲波；樂音（音調、響度、音品）；噪音與聲強級

**電和磁**

- 電荷與庫倫定律；電場與電場強度
- 電流；電勢差與電動勢；電阻與歐姆定律；電阻率與溫度的影響；串聯與並聯；簡單電路與內阻；電功率；家居用電與安全
- 磁力與磁場；電流的磁效應；磁場中的力；電磁感應；交流電的方均根值；變壓器；高壓輸電

**放射現象和核能**

- X 射線；α、β 和 γ 輻射；放射衰變與半衰期；輻射探測；輻射安全
- 原子結構與核素符號；同位素與放射嬗變
- 核裂變與核聚變；質能關係

## 三種批改

| 題型 | 誰批 | 學生看到什麼 |
| --- | --- | --- |
| 選擇 | 程式對答案 | 對或錯，並用課程語言說明該選項錯在哪 |
| 數值 | 程式對最終數值、單位，以及你預先寫下的常見錯答 | 錯在哪一步，例如把比熱容量做成熱容量、溫差用了末溫 |
| 結構、需要步驟分的計算 | 語言模型對着評分準則 | 每點得到或未得，缺的那點寫成訂正，並給一段參考講法 |

選擇題和純數值題不送去模型。結構題送出的只有題幹、評分準則、學生作答，不送姓名、班別、電郵。

標準答案和評分準則放在伺服器。原型為了離線能改，暫時把答案放在頁面裡，正式版不能這樣。

數值題的常見錯答由你決定給幾分。示範題「鋁的比熱容量」把 `Q/m`、`Q/ΔT`、用了末溫這幾種錯法各記 1 分，數值對而單位錯記 2 分，全對 3 分。題目格式見 `docs/question.sample.json`。

結構題的示範是「蒸發為何帶來冷卻」，三點各 1 分：動能較高的分子離開；留下的分子平均動能下降；因此溫度下降。側欄 DeepSeek 貼上金鑰後，這題改由 `deepseek-flash` 判斷要點是否達到，同義說法可以得分。未貼金鑰時仍用要點對照，方便離線看畫面。

## 掌握程度

每個知識點取最近 8 次作答。由舊到新的權重是 1、1、1、2、2、3、3、4。不足 8 次時用這串權重的末段，所以最近一次最重。

得分率 = 加權後的所得分數 / 加權後的滿分。

| 等級 | 條件 |
| --- | --- |
| 未開始 | 還沒有作答 |
| 初學 | 得分率低於 40% |
| 發展中 | 40% 至 69% |
| 穩定 | 70% 至 84% |
| 初步掌握 | 得分率至少 85%，但未滿 4 次 |
| 掌握 | 得分率至少 85%，而且至少 4 次 |

課題掌握 = 該課題裡已作答知識點的得分率平均。未作答的只計入覆蓋，不當成 0 分，否則沒教的課題會把整體拉得很低。

整體掌握 = 五個課題按 23、50、47、48、16 小時加權。

畫面上的「初學知識點」就是薄弱清單。原型為了交卷後立刻看到數字變化，用的是累計平均；正式版用上面的最近 8 次。

## 錯題本

| 狀態 | 何時 |
| --- | --- |
| 待重做 | 這題第一次未拿滿分 |
| 重做仍錯 | 之後再做仍未滿分 |
| 已掌握 | 之後有一次滿分 |

已掌握的題留在本裡，可以用篩選藏起。錯因用批改回傳的那一句，例如「未除以溫差」「實正虛負用反」。錯題總結就是按課題、知識點數這些未掌握的題，不另接分析服務。

## 運行時要接的

| 項目 | 要不要外接 |
| --- | --- |
| 選擇題、數值題批改 | 不要。程式處理 |
| 結構題批改和訂正 | 要。DeepSeek，模型 `deepseek-flash`。金鑰只存在瀏覽器，不寫進專案 |
| 章節掌握、薄弱點、錯題本 | 不要。用自己的作答紀錄計算 |
| 登入 | 可先用帳號密碼。要接學校帳號再加 |
| 學生拍照手寫步驟 | 這版不做。要做才用能看圖的模型 |
| 畫面上的課題線描 | 已經做好，運行時不再呼叫圖像 API |

圖像只用在課題識別：熱、力、波、電、放射各一幅，加上標誌。題目本身仍用文字和公式，不把每題做成圖片。

這個儲存庫已經有一個 GitHub Pages，來源是 `main` 的根目錄，網址是 `https://lucas151129.github.io/cloudAIAgent/`。一個儲存庫只有一個 Pages。物理原型在 `prototype/`，合併後會在 `https://lucas151129.github.io/cloudAIAgent/prototype/`，不會取代天天游戲的首頁。不要改根目錄的 `index.html`，也不要把 Pages 來源改去別的資料夾。

## 題庫先不收的內容

以下依該課程文件的教師說明，超綱的不進預設練習。題目可標 `inScope: false` 先存着。

- 熱：溫度計的詳細結構；用分子解釋對流；影響傳導率的因素；阿佛加德羅定律、臨界溫度；熱力學第一定律和各種循環；推導分子運動的壓強公式；玻耳茲曼常數。
- 力：相對速度；動摩擦和靜摩擦的公式；物體穩度；空氣阻力的定量處理；推導射程、飛行時間、最大高度和軌跡方程；彈性勢能公式；非勻速圓周、汽車翻倒、離心機；行星內部的引力場、開普勒定律、逃逸速度。
- 波動：惠更斯原理；任意兩點的相位差（只要求同相和反相）；干涉再加上繞射的定量；聲波駐波；複式透鏡、視覺缺陷；氣楔和肥皂膜；推導雙縫和光柵公式；聲強級的定義公式和等響曲線。
- 電和磁：尖端作用；安培計、伏特計、動圈式電流計的內部結構；用分流器或倍加器改裝電錶；用安培定律推導磁場所用公式；示波器的詳細結構。
- 放射：X 射線譜和產生的詳細原理；輻射衰減的定量計算；用對數座標畫衰變曲線；推導衰變指數律；把計數率換算成貝克勒耳；核電廠、控制棒和減速劑的結構。

直角分叉碰撞只認「質量相同、彈性」這個條件，不要求證明，也不延伸到不同質量或有動能損失的情況。

## 原型和正式版

原型可以點：課題掌握、三題批改（選擇、數值、蒸發解釋）、錯題本狀態會隨作答改變、班別的薄弱清單。按「還原示例數據」回到起點。原型放在 `prototype/`，沒有改現有的天天游戲網站。

正式版在這套框架上加：帳號、把題庫按上面的格式匯入、批改改到伺服器、掌握改成最近 8 次加權。選修、手寫拍照、公開排名都不在第一版。
